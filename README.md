# Дополнительный функционал (Branch: addons)

Эта ветка содержит расширенные возможности мобильного приложения "Мои шаги", направленные на демонстрацию работы с системными сервисами Android. С информацией о приложении и его базовым функционалом можно ознакомиться в ветке **[master](https://github.com/Shalaginov-VD/SCApplication/tree/master)**.

## 🌟 Список нововведений

### 1. Фрагмент настроек (Settings Fragment) ⚙️
- **Реализован новый раздел**, выступающий единой точкой управления всеми дополнительными функциями приложения.
- **Возможности:**
    - Управление звуковым сопровождением и темой приложения.
    - Переключение локализации (RU/EN) с корректным обновлением ресурсов.
    - Интерактивная установка целей с мгновенной обратной связью.

### 2. Локализация и адаптивность 🌍🌙
- Полная поддержка русского и английского языков для всех элементов интерфейса.
- **Night Mode:** Темы в `themes.xml` оптимизированы для корректного отображения кнопок и полей ввода (EditText) в темном режиме с использованием кастомных HEX-цветов.

### 3. Система персональных целей (Step Goal) 🥇
- В фрагменте настроек добавлена возможность установить ежедневную цель по количеству шагов.
- Использование `SharedPreferences` для сохранения данных и их синхронизации между экранами в реальном времени.

### 4. Push-уведомления 🔔
- При достижении поставленной цели приложение мгновенно отправляет поздравительное уведомление.
- Добавлен флаг-предохранитель, который предотвращает повторную отправку уведомления в течение одного дня.

### 5. Мультимедийная навигация 🔊
- Каждое переключение между вкладками (Home, History, Settings) сопровождается звуковым откликом в формате `.mp3`.
- **Управление:** В настройки добавлен переключатель для полного отключения звуковых эффектов приложения.
